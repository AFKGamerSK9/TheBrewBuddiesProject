Modern C++ Features to Implement Next

Object-Oriented Models (struct / class): Define strong C++ classes for Product, User, and Review instead of returning hardcoded JSON strings. Use modern JSON libraries (like nlohmann/json) to serialize C++ objects directly to JSON response strings.

Database Integration (SQLite / PostgreSQL): Replace static JSON strings with database queries using SQLite C++ wrappers or libpqxx.

Asynchronous / Thread Pool Workers: Leverage C++11/17 std::async, std::future, or std::thread to handle background logging or processing without blocking server HTTP threads.

RAII & Smart Pointers (std::unique_ptr, std::shared_ptr): Automatically manage memory and server resource lifecycles without manual memory management or memory leaks.

C++20 Modules or Templates: Utilize C++20 features for fast compile times and generic controller interfaces.
